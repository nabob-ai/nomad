# 内置工具示例

nomad 提供了一组开箱即用的内置工具,无需配置即可使用。本文档详细介绍每个内置工具的用法和示例。

## 📦 工具列表

| 工具名称          | 功能         | 沙箱 | 示例                  |
| ----------------- | ------------ | ---- | --------------------- |
| `Read`            | 读取文件     | ✅   | [→](#read)            |
| `Write`           | 写入文件     | ✅   | [→](#write)           |
| `Edit`            | 编辑文件     | ✅   | [→](#edit)            |
| `Glob`            | 文件匹配     | ✅   | [→](#glob)            |
| `Grep`            | 文本搜索     | ✅   | [→](#grep)            |
| `Bash`            | 执行命令     | ✅   | [→](#bash)            |
| `TodoWrite`       | 任务管理     | ✅   | [→](#todowrite)       |
| `Task`            | 子任务执行   | ✅   | [→](#task)            |
| `HttpRequest`     | HTTP 请求    | ❌   | [→](#httprequest)     |
| `WebSearch`       | 网络搜索     | ❌   | [→](#websearch)       |
| `Skill`           | 技能调用     | ✅   | [→](#skill)           |

- ✅ - 在沙箱中执行,文件操作限制在工作目录内
- ❌ - 直接执行,访问外部网络资源

## 🚀 快速开始

### 注册所有内置工具

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/nabob-ai/nomad/pkg/agent"
    "github.com/nabob-ai/nomad/pkg/sandbox"
    "github.com/nabob-ai/nomad/pkg/store"
    "github.com/nabob-ai/nomad/pkg/tools"
    "github.com/nabob-ai/nomad/pkg/tools/builtin"
    "github.com/nabob-ai/nomad/pkg/types"
)

func main() {
    ctx := context.Background()

    // 1. 创建工具注册表
    toolRegistry := tools.NewRegistry()

    // 2. 注册所有内置工具
    builtin.RegisterAll(toolRegistry)

    // 3. 创建其他依赖...
    sandboxFactory := sandbox.NewFactory()
    jsonStore, _ := store.NewJSONStore(".nomad")
    templateRegistry := agent.NewTemplateRegistry()

    // 4. 注册模板并声明可用工具
    templateRegistry.Register(&types.AgentTemplateDefinition{
        ID:    "assistant",
        Model: "claude-sonnet-4-5",
        SystemPrompt: "You are a helpful assistant with file and command execution capabilities.",
        Tools: []interface{}{
            "Read",            // 文件读取
            "Write",           // 文件写入
            "Edit",            // 文件编辑
            "Glob",            // 文件匹配
            "Grep",            // 文本搜索
            "Bash",            // 命令执行
            "TodoWrite",       // 任务管理
            "Task",            // 子任务执行
            "HttpRequest",     // HTTP 请求
            "WebSearch",       // 网络搜索
            "Skill",           // 技能调用
            "SemanticSearch",  // 语义搜索
            "EnterPlanMode",   // 进入规划模式
            "ExitPlanMode",    // 退出规划模式
            "AskUserQuestion", // 结构化提问
        },
    })

    // 5. 创建依赖对象
    deps := &agent.Dependencies{
        Store:            jsonStore,
        SandboxFactory:   sandboxFactory,
        ToolRegistry:     toolRegistry,
        TemplateRegistry: templateRegistry,
    }

    // 6. 创建 Agent
    config := &types.AgentConfig{
        TemplateID: "assistant",
        ModelConfig: &types.ModelConfig{
            Provider: "anthropic",
            Model:    "claude-sonnet-4-5",
            APIKey:   os.Getenv("ANTHROPIC_API_KEY"),
        },
        Sandbox: &types.SandboxConfig{
            Kind:    types.SandboxKindLocal,
            WorkDir: "./workspace",
        },
    }

    ag, err := agent.Create(ctx, config, deps)
    if err != nil {
        log.Fatalf("Failed to create agent: %v", err)
    }
    defer ag.Close()

    fmt.Printf("Agent created: %s\n", ag.ID())

    // 7. 使用内置工具
    testBuiltinTools(ctx, ag)
}
```

## 🔧 工具详解

### <a id="read"></a>📖 Read - 文件读取

从沙箱文件系统读取文件内容，支持分页和文件类型识别。

**输入参数：**

```typescript
{
  "file_path": string,   // 文件路径（必须是绝对路径）
  "offset"?: number,     // 起始行号（从1开始，默认为1）
  "limit"?: number       // 最大读取行数（默认读取整个文件）
}
```

**使用示例：**

```go
// 示例 1: 读取整个文件
result, err := ag.Chat(ctx, "请读取 config.json 文件的内容")
// Agent 将调用: Read(file_path="/workspace/config.json")

// 示例 2: 读取部分内容
result, err := ag.Chat(ctx, "请读取 README.md 的前 10 行")
// Agent 将调用: Read(file_path="/workspace/README.md", limit=10)

// 示例 3: 从指定位置读取
result, err := ag.Chat(ctx, "请从第 50 行开始读取 data.txt，读取 20 行")
// Agent 将调用: Read(file_path="/workspace/data.txt", offset=50, limit=20)
```

**返回格式：**

```json
{
  "ok": true,
  "file_path": "/workspace/config.json",
  "content": "文件内容...",
  "lines": 42,
  "offset": 1,
  "limit": 0,
  "truncated": false,
  "total_lines": 42,
  "file_size": 1024,
  "file_type": "json",
  "duration_ms": 5
}
```

### <a id="write"></a>✏️ Write - 文件写入

向沙箱文件系统写入文件，支持目录创建、备份和追加模式。

**输入参数：**

```typescript
{
  "file_path": string,    // 文件路径（必须是绝对路径）
  "content": string,      // 文件内容
  "create_dirs"?: boolean, // 是否自动创建父目录（默认true）
  "backup"?: boolean,     // 是否创建备份（默认false）
  "append"?: boolean      // 是否追加模式（默认false）
}
```

**使用示例：**

```go
// 示例 1: 创建新文件
result, err := ag.Chat(ctx, "请创建一个名为 hello.txt 的文件，内容是 'Hello World'")
// Agent 将调用: Write(file_path="/workspace/hello.txt", content="Hello World")

// 示例 2: 追加内容
result, err := ag.Chat(ctx, "请在 log.txt 文件末尾添加新日志行")
// Agent 将调用: Write(file_path="/workspace/log.txt", content="新的日志行", append=true)

// 示例 3: 带备份的覆盖
result, err := ag.Chat(ctx, "请备份 config.json 然后更新配置")
// Agent 将调用: Write(file_path="/workspace/config.json", content="{...}", backup=true)
```

**返回格式：**

```json
{
  "ok": true,
  "file_path": "/workspace/hello.txt",
  "content": "Hello World",
  "lines": 1,
  "file_size": 11,
  "file_type": "text",
  "duration_ms": 3,
  "append_mode": false,
  "created_dirs": false,
  "file_existed": false,
  "operation": "created"
}
```

### <a id="edit"></a>✏️ Edit - 文件编辑

在文件中精确查找并替换文本内容。

**输入参数：**

```typescript
{
  "file_path": string,           // 文件路径（必须是绝对路径）
  "old_string": string,          // 要被替换的文本
  "new_string": string,          // 新的文本
  "replace_all"?: boolean,       // 是否替换所有匹配项（默认false）
  "preserve_indentation"?: boolean // 是否保持缩进（默认true）
}
```

**使用示例：**

```go
// 示例 1: 替换单个字符串
result, err := ag.Chat(ctx, "请将 config.json 中的 'debug': false 改为 'debug': true")
// Agent 将调用: Edit(file_path="/workspace/config.json", old_string="'debug': false", new_string="'debug': true")

// 示例 2: 替换所有匹配项
result, err := ag.Chat(ctx, "请将文件中所有的 'TODO' 替换为 'DONE'")
// Agent 将调用: Edit(file_path="/workspace/notes.txt", old_string="TODO", new_string="DONE", replace_all=true)
```

**返回格式：**

```json
{
  "ok": true,
  "file_path": "/workspace/config.json",
  "changes_made": 1,
  "duration_ms": 8
}
```

### <a id="glob"></a>🔍 Glob - 文件匹配

使用 glob 模式匹配查找文件。

**输入参数：**

```typescript
{
  "pattern": string,         // glob 模式
  "path"?: string,          // 搜索路径（默认当前目录）
  "recursive"?: boolean     // 是否递归搜索（默认true）
}
```

**使用示例：**

```go
// 示例 1: 查找所有 JSON 文件
result, err := ag.Chat(ctx, "请查找所有 .json 文件")
// Agent 将调用: Glob(pattern="**/*.json")

// 示例 2: 在特定目录查找
result, err := ag.Chat(ctx, "请在 src 目录下查找所有 Go 文件")
// Agent 将调用: Glob(pattern="**/*.go", path="src")
```

### <a id="grep"></a>🔍 Grep - 文本搜索

使用正则表达式在文件中搜索文本。

**输入参数：**

```typescript
{
  "pattern": string,                    // 正则表达式
  "path"?: string,                     // 搜索路径（默认当前目录）
  "glob"?: string,                     // 文件过滤模式
  "file_type"?: string,                // 文件类型过滤
  "output_mode"?: string,              // 输出模式：content/files_with_matches/count
  "max_results"?: number,              // 最大结果数
  "case_sensitive"?: boolean           // 是否大小写敏感（默认false）
}
```

**使用示例：**

```go
// 示例 1: 搜索错误日志
result, err := ag.Chat(ctx, "请在日志文件中搜索所有 ERROR 信息")
// Agent 将调用: Grep(pattern="ERROR", glob="*.log")

// 示例 2: 查找函数定义
result, err := ag.Chat(ctx, "请查找所有名为 'processData' 的函数定义")
// Agent 将调用: Grep(pattern="func.*processData", file_type="go")
```

**返回格式：**

```json
{
  "ok": true,
  "pattern": "ERROR",
  "path": ".",
  "output_mode": "content",
  "matches": [
    {
      "file": "app.log",
      "line_number": 42,
      "line": "2023-10-01 10:30:15 ERROR: Database connection failed"
    }
  ],
  "total_matches": 5,
  "files_scanned": 3,
  "duration_ms": 15
}
```

### <a id="bash"></a>⚡ Bash - 命令执行

在沙箱环境中执行 Bash 命令，支持持久化会话。

**输入参数：**

```typescript
{
  "command": string,                // 要执行的命令
  "timeout"?: number,               // 超时时间（毫秒，默认120000）
  "working_dir"?: string,           // 工作目录
  "shell"?: string,                 // shell类型（bash/sh/zsh，默认bash）
  "background"?: boolean,           // 是否后台运行（默认false）
  "environment"?: object,           // 环境变量
  "capture_output"?: boolean        // 是否捕获输出（默认true）
}
```

**使用示例：**

```go
// 示例 1: 列出文件
result, err := ag.Chat(ctx, "请列出当前目录的所有文件")
// Agent 将调用: Bash(command="ls -la")

// 示例 2: 带环境变量的命令
result, err := ag.Chat(ctx, "请设置环境变量 DEBUG=true 并运行应用")
// Agent 将调用: Bash(command="npm start", environment={"DEBUG": "true"})
```

**返回格式：**

```json
{
  "ok": true,
  "command": "ls -la",
  "exit_code": 0,
  "success": true,
  "stdout": "total 16\ndrwxr-xr-x  4 user  group   128 Oct  1 10:30 .\n...",
  "stderr": "",
  "duration_ms": 42,
  "background": false,
  "shell_type": "bash"
}
```

### <a id="httprequest"></a>🌐 HttpRequest - HTTP 请求

发送 HTTP 请求到外部 API，支持多种请求方法和认证。

**输入参数：**

```typescript
{
  "url": string,                    // 请求 URL
  "method"?: string,                // HTTP 方法（默认GET）
  "headers"?: object,               // 请求头
  "body"?: string,                  // 请求体
  "timeout_seconds"?: number        // 超时时间（秒，默认30）
}
```

**使用示例：**

```go
// 示例 1: GET 请求
result, err := ag.Chat(ctx, "请获取 GitHub 用户信息")
// Agent 将调用: HttpRequest(url="https://api.github.com/users/octocat", method="GET")

// 示例 2: POST 请求
result, err := ag.Chat(ctx, "请向 API 发送用户创建请求")
// Agent 将调用: HttpRequest(
//   url="https://api.example.com/users",
//   method="POST",
//   headers={"Content-Type": "application/json"},
//   body='{"name": "Alice", "email": "alice@example.com"}'
// )
```

**返回格式：**

```json
{
  "ok": true,
  "status_code": 200,
  "headers": { "Content-Type": "application/json" },
  "body": "{...}",
  "duration_ms": 156
}
```

### <a id="enterplanmode"></a>📋 EnterPlanMode - 进入规划模式

进入规划模式，用于复杂任务的规划阶段。在此模式下只允许只读操作和计划文件写入。

**使用场景：**

- 多种有效方案 - 任务可以用多种方式解决，需要权衡
- 重大架构决策 - 需要在架构模式之间做选择
- 大规模变更 - 任务涉及多个文件或系统
- 需求不明确 - 需要先探索才能理解完整范围
- 需要用户确认 - 需要向用户提问以确认方向

**输入参数：**

```typescript
{
  "reason"?: string               // 进入规划模式的原因说明
}
```

**使用示例：**

```go
// 示例 1: 进入规划模式
result, err := ag.Chat(ctx, "这个任务比较复杂，我需要先规划一下")
// Agent 将调用: EnterPlanMode(reason="需要设计用户认证系统，有多种方案可选")
```

**返回格式：**

```json
{
  "ok": true,
  "plan_file_path": ".nomad/plans/sunny-singing-nygaard.md",
  "plan_id": "sunny-singing-nygaard",
  "allowed_tools": ["Read", "Glob", "Grep", "WebFetch", "WebSearch", "AskUserQuestion", "Write"],
  "workflow": "## Plan Mode Workflow\n...",
  "message": "Plan mode activated. You can now explore the codebase and create your plan.",
  "next_steps": ["1. Read the codebase to understand existing patterns", "2. Ask user questions to clarify requirements", "3. Update the plan file with your findings", "4. Call ExitPlanMode when ready for user approval"],
  "constraints": {
    "read_only": true,
    "plan_file_writable": ".nomad/plans/sunny-singing-nygaard.md",
    "code_editing_disabled": true,
    "bash_disabled": true
  }
}
```

**规划模式限制：**

- ✅ 允许：Read, Glob, Grep（读取文件）
- ✅ 允许：WebFetch, WebSearch（搜索网页）
- ✅ 允许：AskUserQuestion（向用户提问）
- ✅ 允许：Write（仅限计划文件）
- ❌ 禁止：编辑代码文件
- ❌ 禁止：运行 Bash 命令
- ❌ 禁止：创建或删除文件（除计划文件外）

**输入参数：**

```typescript
{
  "plan_file_path"?: string      // 计划文件路径（可选，默认使用最新的计划文件）
```

**使用示例：**

```go
// 示例 1: 退出规划模式（自动使用最新计划）
result, err := ag.Chat(ctx, "规划完成，请用户审批")
// Agent 将调用: ExitPlanMode()

// 示例 2: 指定计划文件
// Agent 将调用: ExitPlanMode(plan_file_path=".nomad/plans/sunny-singing-nygaard.md")
```

**返回格式：**

```json
{
  "ok": true,
  "plan_id": "sunny-singing-nygaard",
  "plan_file_path": ".nomad/plans/sunny-singing-nygaard.md",
  "plan_content": "# Implementation Plan\n...",
  "status": "pending_approval",
  "confirmation_required": true,
  "duration_ms": 5,
  "message": "Plan is ready for user review. The user will see the plan content and can approve or request changes.",
  "next_steps": ["User needs to review the plan", "After approval, implementation can begin", "User can request modifications if needed"]
}
```

### <a id="askuserquestion"></a>❓ AskUserQuestion - 结构化提问

向用户提出结构化问题，用于澄清需求、确认方案或收集偏好。

**使用场景：**

- 收集用户偏好或需求
- 澄清模糊的指令
- 获取实施方案的决策
- 提供选择让用户决定方向

**输入参数：**

```typescript
{
  "questions": [                   // 问题列表（1-4个问题）
    {
      "question": string,          // 完整的问题文本
      "header": string,            // 简短标签（最多12字符）
      "options": [                 // 选项列表（2-4个选项）
        {
          "label": string,         // 选项标签（1-5个词）
          "description": string    // 选项说明
        }
      ],
      "multi_select"?: boolean     // 是否允许多选（默认false）
    }
  ]
}
```

## ❓ 常见问题

### Q: 如何只启用部分内置工具？

只在模板中声明需要的工具：

```go
templateRegistry.Register(&types.AgentTemplateDefinition{
    ID:    "file-only-assistant",
    Tools: []interface{}{
        "Read",   // 只启用文件读取
        "Write",  // 只启用文件写入
    },
})
```

### Q: 工具调用会计入 Token 使用吗？

是的。工具调用的输入和输出都会计入 Token 使用。建议：

- 读取大文件时使用 offset 和 limit
- 避免频繁调用同一工具
- 使用 Grep 工具进行文本搜索而不是读取大文件后手动搜索
- 使用 Glob 工具查找文件而不是用 Bash 命令

### Q: 如何限制文件访问范围？

通过沙箱配置限制工作目录：

```go
config := &types.AgentConfig{
    Sandbox: &types.SandboxConfig{
        Kind:    types.SandboxKindLocal,
        WorkDir: "./restricted-workspace",  // 只能访问这个目录
    },
}
```

### Q: 可以禁用某些危险命令吗？

可以。Bash 工具内置了安全检查，会自动阻止危险命令如：

- `rm -rf /` - 系统删除命令
- `sudo rm` - 需要管理员权限的删除
- `dd if=/dev/zero` - 磁盘破坏命令
- `format` / `fdisk` - 磁盘格式化命令

也可以通过沙箱配置进一步限制：

```go
config := &types.SandboxConfig{
    Kind:    types.SandboxKindLocal,
    WorkDir: "./workspace",
    BlockedCommands: []string{
        "rm -rf",
        "dd",
        "mkfs",
    },
}
```

### Q: 新的工具名称有什么优势？

新的工具名称更加直观和一致：

1. **更简洁**: `Read` 比 `Read` 更简洁
2. **更直观**: `Write` 比 `Write` 更直观
3. **更一致**: 所有工具都使用 PascalCase 命名
4. **更完整**: 新增了 `Edit`、`Glob`、`Grep`、`TodoWrite`、`Task`、`Skill`、`SemanticSearch` 等工具
5. **功能更强大**: 每个工具都有更多的参数选项和更好的错误处理
