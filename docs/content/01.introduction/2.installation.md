# 安装指南

本指南将帮助您配置nomad的开发环境。

## 📋 前置要求

### Go环境

nomad需要**Go 1.24或更高版本**。

检查Go版本：

```bash
go version
```

如果未安装Go，请访问 [Go官网](https://golang.org/dl/) 下载安装。

### 推荐配置

- **操作系统**：Linux、macOS或Windows
- **内存**：至少4GB RAM
- **磁盘空间**：至少500MB可用空间

### API密钥

您需要至少一个大模型提供商的API密钥：

- **Anthropic**: [获取密钥](https://console.anthropic.com/)
- **OpenAI**: [获取密钥](https://platform.openai.com/)
- **DeepSeek**: [获取密钥](https://platform.deepseek.com/)

## 📦 安装nomad

### 方式1：使用go get（推荐）

```bash
go get github.com/nabob-ai/nomad
```

### 方式2：在项目中使用

在你的Go项目中：

```bash
# 初始化Go模块（如果还未初始化）
go mod init your-project-name

# 添加nomad依赖
go get github.com/nabob-ai/nomad
```

这会自动下载nomad及其所有依赖。

### 方式3：从源码构建

```bash
# 克隆仓库
git clone https://github.com/nabob-ai/nomad.git
cd nomad

# 下载依赖
go mod download

# 运行测试（可选）
go test ./...
```

## 🔑 配置API密钥

### 环境变量（推荐）

创建 `.env` 文件：

```bash
# Anthropic
export ANTHROPIC_API_KEY="sk-ant-xxxxx"

# OpenAI
export OPENAI_API_KEY="sk-xxxxx"

# DeepSeek
export DEEPSEEK_API_KEY="sk-xxxxx"
```

加载环境变量：

```bash
source .env
```

### 代码中配置

```go
import "github.com/nabob-ai/nomad/pkg/provider"

// Anthropic
p := provider.NewAnthropicProvider("your-api-key")

// OpenAI
p := provider.NewOpenAIProvider("your-api-key")

// DeepSeek
p := provider.NewDeepSeekProvider("your-api-key")
```

## 🛠️ 可选：沙箱配置

### 本地沙箱（默认）

本地沙箱无需额外配置，开箱即用。

### Docker沙箱

如果需要Docker沙箱：

```bash
# 安装Docker
# macOS: https://docs.docker.com/desktop/mac/install/
# Linux: https://docs.docker.com/engine/install/
# Windows: https://docs.docker.com/desktop/windows/install/

# 验证安装
docker --version
```

### 云端沙箱

#### 阿里云AgentBay

1. 开通[阿里云AgentBay服务](https://www.aliyun.com/product/agentbay)
2. 获取AccessKey和SecretKey
3. 配置环境变量：

```bash
export ALIYUN_ACCESS_KEY_ID="your-access-key"
export ALIYUN_ACCESS_KEY_SECRET="your-secret-key"
export ALIYUN_REGION="cn-hangzhou"
```

#### 火山引擎沙箱

1. 开通[火山引擎服务](https://www.volcengine.com/)
2. 获取AK/SK
3. 配置环境变量：

```bash
export VOLC_ACCESS_KEY_ID="your-access-key"
export VOLC_SECRET_ACCESS_KEY="your-secret-key"
export VOLC_REGION="cn-beijing"
```

## 🐛 常见问题

### 问题1：go get失败

**症状**：网络连接超时或被拒绝

**解决方案**：配置Go代理

```bash
# 中国大陆用户推荐
go env -w GOPROXY=https://goproxy.cn,direct

# 或使用阿里云镜像
go env -w GOPROXY=https://mirrors.aliyun.com/goproxy/,direct
```

### 问题2：找不到模块

**症状**：`cannot find module`

**解决方案**：

```bash
# 清理缓存
go clean -modcache

# 重新下载
go mod download

# 更新依赖
go get -u github.com/nabob-ai/nomad
```

### 问题3：权限错误

**症状**：`permission denied`

**解决方案**：

```bash
# 确保Go安装目录有写权限
sudo chown -R $USER:$USER $(go env GOPATH)
```

### 问题4：版本冲突

**症状**：依赖版本不兼容

**解决方案**：

```bash
# 更新到最新版本
go get -u github.com/nabob-ai/nomad@latest

# 或指定版本
go get github.com/nabob-ai/nomad@v0.1.0

# 整理依赖
go mod tidy
```

## 📦 项目模板

推荐的项目结构：

```
my-agent-project/
├── go.mod
├── go.sum
├── .env                 # API密钥（不要提交到Git）
├── .gitignore
├── main.go
├── agents/              # Agent定义
│   ├── assistant.go
│   └── coder.go
├── tools/               # 自定义工具
│   └── custom_tool.go
├── middleware/          # 自定义中间件
│   └── logger.go
└── workspace/           # 沙箱工作目录
```

示例 `.gitignore`：

```gitignore
# 环境变量
.env
.env.local

# 工作目录
workspace/
.nomad/

# Go构建
*.exe
*.exe~
*.dll
*.so
*.dylib
*.test
*.out

# 依赖
vendor/
```
